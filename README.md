# Квиз «Конец Смуты» — ВИТШ Медиа

Одна страница без сборки: `index.html` + `questions.js` (вопросы и факты) + `config.js` (куда сохранять результаты) + `brand.js` (копия `brand/brand.js`).
Сайт — на GitHub Pages, результаты — в Google Таблицу через Apps Script (бесплатно, без сервера).

## 1. Таблица для результатов (5 минут, один раз)
1. Создай Google Таблицу, например «Конец Смуты — результаты».
2. **Расширения → Apps Script**, удали всё в редакторе и вставь код из `apps-script.gs`. Сохрани.
3. **Развернуть → Новое развёртывание → Тип: Веб-приложение.**
   - Выполнять как: **Я**
   - У кого есть доступ: **Все**
4. Разреши доступ к таблице (Google предупредит, что приложение не проверено, — это твой же скрипт: «Дополнительно → Перейти»).
5. Скопируй URL веб-приложения (заканчивается на `/exec`) и вставь в `config.js`:
   ```js
   window.QUIZ_ENDPOINT = "https://script.google.com/macros/s/…/exec";
   ```
В таблице появится лист «Результаты»: время, имя и группа, баллы, номер попытки, время прохождения и строка ответов (`1` — верно).
Каждая попытка пишется отдельной строкой; лучших удобно искать сортировкой по баллам и времени.

Если поменяешь код скрипта — **Развернуть → Управление развёртываниями → Изменить → Новая версия**, иначе останется старый.

## 2. Публикация на GitHub Pages
Содержимое этой папки — в отдельный публичный репозиторий (например `vitsh-quiz`), затем
**Settings → Pages → Deploy from a branch → main / (root)**. Через минуту сайт будет по адресу
`https://<аккаунт>.github.io/vitsh-quiz/`.

В `index.html` в `og:image` указан адрес `https://qwerty-ll.github.io/vitsh-quiz/og.png` — если репозиторий будет в другом аккаунте или с другим именем, поправь.

## 3. Проверка перед постом
- Пройди квиз сам с телефона — в таблице должна появиться строка.
- Вставь ссылку в черновик поста ВК — должно подтянуться превью с картинкой `og.png`.
  Если ВК показывает старое превью, обнови его через https://vk.com/dev/pages.clearCache.

## Как поменять вопросы
`questions.js`: первый вариант ответа — правильный (на экране варианты перемешиваются), `fact` — пояснение после ответа, `ranks` — звания по баллам.
