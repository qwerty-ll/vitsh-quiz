# Квиз «Конец Смуты» — ВИТШ Медиа

Одна страница без сборки: `index.html` + `questions.js` (вопросы и факты) + `config.js` (куда сохранять результаты) + `brand.js` (копия `brand/brand.js`).
Сайт — на GitHub Pages, результаты — в Google Таблицу через Apps Script (бесплатно, без сервера).

## 1. Таблица для результатов (5 минут, один раз)
1. Создай Google Таблицу, например «Конец Смуты — результаты».
2. **Расширения → Apps Script**, удали всё в редакторе и вставь код из `apps-script.gs`. Сохрани.
3. **Развернуть → Новое развёртывание → Тип: Веб-приложение.**
   - Выполнять как: **Я**
   - У кого есть доступ: **Все**
4. Разреши доступ к таблице (Google предупредит, что приложение не проверено, — это твой же скрипт: «Дополнительно → Перейти»).
5. Скопируй URL веб-приложения (заканчивается на `/exec`) и вставь в `config.js`:
   ```js
   window.QUIZ_ENDPOINT = "https://script.google.com/macros/s/…/exec";
   ```
В таблице появится лист «Результаты»: время, код попытки, баллы, номер попытки, время прохождения и строка ответов (`1` — верно).
Баллы скрипт считает сам по строке ответов.
Каждая попытка пишется отдельной строкой.

**Персональные данные не собираем.** Имён, групп, контактов и IP в таблице нет — только анонимная статистика.
Так квиз не попадает под 152-ФЗ: не нужны согласие на обработку, политика конфиденциальности и хранение данных на серверах в России.
Победителя находим по коду (см. «Розыгрыш» ниже) — имя он сообщает сам, в сообщениях сообщества.

### Если скрипт уже был развёрнут раньше
Вставь новый код из `apps-script.gs` и выбери **Развернуть → Управление развёртываниями → Изменить → Новая версия** (адрес не поменяется).
В старой таблице переименуй заголовок второго столбца «Имя и группа» в «Код» — остальные столбцы совпадают.

Если поменяешь код скрипта — **Развернуть → Управление развёртываниями → Изменить → Новая версия**, иначе останется старый.

## 2. Публикация на GitHub Pages
Содержимое этой папки — в отдельный публичный репозиторий (например `vitsh-quiz`), затем
**Settings → Pages → Deploy from a branch → main / (root)**. Через минуту сайт будет по адресу
`https://<аккаунт>.github.io/vitsh-quiz/`.

В `index.html` в `og:image` указан адрес `https://qwerty-ll.github.io/vitsh-quiz/og.png` — если репозиторий будет в другом аккаунте или с другим именем, поправь.

## 3. Проверка перед постом
- Пройди квиз сам с телефона — в таблице должна появиться строка.
- Вставь ссылку в черновик поста ВК — должно подтянуться превью с картинкой `og.png`.
  Если ВК показывает старое превью, обнови его через https://vk.com/dev/pages.clearCache.

## Как поменять вопросы
`questions.js`: первый вариант ответа — правильный (на экране варианты перемешиваются), `fact` — пояснение после ответа, `ranks` — звания по баллам.

## Розыгрыш
Приз разыгрываем среди тех, кто ответил верно на все 20 вопросов. Имён в таблице нет: в конце квиза каждая попытка получает случайный код, например `7KQ-M4P`.

1. В `config.js` укажи ссылку на сообщения сообщества: `window.QUIZ_PRIZE = { vk: "https://vk.me/<короткое имя>", until: "6 ноября, 23:59" }` — у тех, кто ответил на 20 из 20, появится кнопка «Отправить код в сообщения». Сообщения сообщества должны быть включены.
2. **Приём заявок до срока.** Нашёл код в таблице (Ctrl+F), в строке «Баллы» = 20 — заявка принята. Один аккаунт ВК — одна заявка, даже если человек прислал несколько кодов.
3. **Подозрительные заявки:** код не найден, баллы меньше 20 или «Секунд» меньше ~60 (20 вопросов с чтением фактов так быстро не пройти).
4. **Выбор победителя:** пронумеруй принятые заявки по порядку, выбери номер на random.org (запиши экран — так честнее) и опубликуй код победителя. Имя — только если победитель согласен.
5. **Вручение:** договоритесь в сообщениях, где забрать приз, например в медиацентре.
6. **Приз до 4000 ₽** — тогда победителю не нужно платить НДФЛ (п. 28 ст. 217 НК РФ).
7. После розыгрыша переписку в таблицу не переносим. Лист «Результаты» можно оставить: в нём только анонимная статистика.

Честно о защите: квиз — статичная страница, ответы есть в её коде, поэтому кто-то может «пройти» его, подглядев. Это не экзамен, поэтому правило «одна заявка с аккаунта» и случайный выбор победителя достаточно уравнивают шансы.
